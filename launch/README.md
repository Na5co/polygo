# Launch kit: drafts only

Nothing in this directory is posted automatically. Each file is a draft to be
read, adjusted and posted by a human, in this order, one community per day:

1. `show-hn.md`: Show HN title + the first comment (post the comment immediately after submitting).
2. `reddit-iosprogramming.md`: leads with `.xcstrings`.
3. `reddit-flutterdev.md`: leads with ARB / `l10n.yaml`.
4. `reddit-androiddev.md`: leads with `strings.xml`.
5. `reddit-reactjs.md`: leads with i18next JSON.
6. `terminal-trove.md`: Terminal Trove submission form fields.
7. `awesome-lists.md`: one-line entries and PR bodies for the awesome-* lists.

Rules that every draft follows (and `scripts/review_launch.sh` re-checks with a
second model): under 300 words, opens with the community's own file format and a
concrete result, says plainly that it is free/MIT/no account, asks a real question
at the end, never links more than once, never mentions stars.
